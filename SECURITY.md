# Security policy

## Supported versions

Security fixes are made in the latest release only. Please update to it
before reporting a problem.

## Reporting a vulnerability

Please do not report security problems in a public issue.

Use GitHub's private reporting instead: on the repository page, open the
**Security** tab and choose **Report a vulnerability**. Only the
maintainer sees the report.

Examples of what to report: a crafted structure file (CIF or other) that
makes the Void run code or write files outside the folders you chose; a
problem with the Windows installer; anything that exposes your files or
data to someone else.

You will get an answer within two weeks. Once a fix is released, the
report can be made public, with credit to you if you wish.

## What the Void does with your data

The Void works on your computer. It reaches the internet only when you
ask it to fetch reference data (CoRE MOF 2024, MOFX-DB). It does not
send your structures or results anywhere.
